CI-CBM: Class-Incremental Concept Bottleneck Model for Interpretable Continual Learning

Amirhosein Javadi, Tuomas Oikarinen, Tara Javidi, Tsui-Wei (Lily) Weng
UC San Diego
TMLR 2026
article Paper code Code

Abstract

  • CI-CBM tackles one of continual learning’s hardest problems: learning new classes over time without forgetting old ones.
  • Unlike black-box continual learning models, CI-CBM keeps decisions interpretable by reasoning through human-understandable concepts.
  • The method does not need to store old training samples, making it more practical for privacy-sensitive and memory-limited settings.
  • CI-CBM introduces concept regularization and pseudo-concept generation to preserve old knowledge while adapting to new classes.
  • Across seven datasets, CI-CBM strongly outperforms prior interpretable continual learning methods, achieving an average accuracy gain of 36%.
  • The model approaches black-box performance while remaining explainable, showing that interpretability and strong accuracy can coexist.
  • CI-CBM provides both local and global explanations, helping users understand why a single prediction was made and how concepts influence each class.
  • The approach works in both pretrained and non-pretrained settings, making it flexible for real-world continual learning scenarios.

Method

CI-CBM builds on label-free concept bottleneck models and adapts them to exemplar-free class-incremental learning: new classes arrive over time, old training data is not stored, and predictions stay grounded in human-readable concepts.

Figure 1. CI-CBM pipeline overview (exported from page 10 of the paper PDF). Full PDF.

  • Initialize concepts. Generate an initial set of human-readable concepts for the first group of classes using language-model prompts.
  • Learn the concept bottleneck. Map image features into a concept space, where each dimension corresponds to an interpretable concept.
  • Train a sparse classifier. Learn a sparse final layer that connects important concepts to class predictions.
  • Expand concepts for new classes. When new classes arrive, generate and filter new concepts, then add only unique and useful concepts to the concept set.
  • Prevent concept drift. Use concept regularization so previously learned concepts keep their meaning while the model learns new ones.
  • Generate pseudo-concepts for old classes. Since old data is unavailable, create pseudo-features and pseudo-concepts using stored class centroids.
  • Update the classifier. Train the final sparse classifier using real concepts for new classes and pseudo-concepts for old classes.

Experiments

1. Concept Prediction

  • CI-CBM consistently outperforms prior interpretable CIL methods across multiple datasets and phase splits.

Figure 2. Example of local concept-based reasoning across phases.

2. Steerability

  • Ablation confirms both concept regularization and pseudo-concepts are necessary for strong incremental performance.
  • Without pseudo-concepts, old-class decision weights collapse and accuracy drops sharply.

Figure 3. CIFAR-100 concept-space analysis (ImageNet-pretrained backbone).

Figure 4. CIFAR-100 concept-space analysis (non-pretrained/FeTrIL setting).

  • Qualitative visualizations show stable and meaningful concept contributions over incremental phases.
  • Pseudo-feature analysis supports the reliability of pseudo-concepts in preserving past knowledge.
  • Performance remains competitive with unrestricted methods in both ResNet and ViT settings.

Figure 5. Global concept-weight structure for Tree Swallow in CUB.

3. Main Ablation

  • Combining concept regularization and pseudo-concepts yields the best average incremental accuracy.
  • This validates that preserving concept functionality and classifier adaptation are complementary.

Figure 6. Distribution view illustrating why pseudo-feature transfer works.

Conclusion

  • CI-CBM provides an effective, interpretable approach for exemplar-free class-incremental learning.
  • It substantially improves over prior interpretable CIL methods while preserving transparent concept-based reasoning.
  • Results across seven datasets show that interpretability and strong incremental performance can coexist.
